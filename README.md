# Версия схемы заметок

У каждой заметки есть целочисленное поле `schema_version`. Актуальная версия схемы задаётся константой `CURRENT_NOTE_SCHEMA_VERSION` в `app/models/note.ts` и используется при создании новых заметок. При изменении формата сохраняемых данных версию схемы нужно увеличить.

Заметки хранятся в `localStorage` браузера под ключом `notes`; для отметки завершённой инициализации используется ключ `notes-initialized`. Каждая сохранённая заметка содержит `schema_version`, а store проверяет структуру данных при чтении. При первой инициализации, если сохранённых заметок ещё нет и флаг инициализации не установлен, создаются две начальные заметки. Хранение работает без внешнего сервиса или дополнительной зависимости.

Черновик сохраняется как снимок всей модели заметки, включая `schema_version`. При открытии приложения версия черновика проверяется до показа предложения продолжить редактирование. Если версия не совпадает с актуальной версией приложения (или не является целым числом), черновик тихо удаляется, и сообщение «Обнаружен черновик, хотите продолжить?» не показывается. Черновик с актуальной версией можно восстановить.

## Тесты

Тесты store заметок (`app/stores/notes.test.ts`) покрывают следующие сценарии:

- первая инициализация с созданием двух начальных заметок и их сохранением;
- восстановление валидных заметок из `localStorage` и обработка некорректных данных;
- защита от повторной инициализации;
- создание заметки с нормализацией заголовка и пунктов чек-листа;
- сохранение существующей заметки, включая случай отсутствующей заметки;
- удаление заметки с сохранением оставшихся данных;
- работа с заметками в памяти, если `localStorage` недоступен.
