# Описание
Веб-приложение для заметок на Nuxt4 + pinia + tailwindcss. Сторонних UI библиотек нет. Заметки и черновик хранятся в localstorage.

# Запуск
```bash
docker-compose up
```

# Версия схемы заметок

У каждой заметки есть целочисленное поле `schema_version`. Актуальная версия схемы задаётся константой `CURRENT_NOTE_SCHEMA_VERSION` в `app/models/note.ts` и используется при создании новых заметок. При изменении формата сохраняемых данных версию схемы нужно увеличить.

Заметки хранятся в `localStorage` браузера под ключом `notes`; для отметки завершённой инициализации используется ключ `notes-initialized`. Каждая сохранённая заметка содержит `schema_version`, а store проверяет структуру данных при чтении. При первой инициализации, если сохранённых заметок ещё нет и флаг инициализации не установлен, создаются две начальные заметки. Хранение работает без внешнего сервиса или дополнительной зависимости.

Черновик сохраняется как снимок всей модели заметки, включая `schema_version`. При открытии приложения версия черновика проверяется до показа предложения продолжить редактирование. Если версия не совпадает с актуальной версией приложения (или не является целым числом), черновик тихо удаляется, и сообщение «Обнаружен черновик, хотите продолжить?» не показывается. Черновик с актуальной версией можно восстановить.

Undo/redo редактора работает только в памяти и не восстанавливает историю после перезагрузки приложения. Ключевые атомарные изменения (добавление, удаление и отметка пункта чек-листа) сразу записываются в историю; изменения заголовков при наборе объединяются и попадают в историю с дебаунсом в 1 секунду через `watchDebounced` из VueUse. Черновик обновляется при каждой записи изменения в историю: поэтому атомарные изменения сохраняются сразу, а набор текста — после debounce, без непрерывной записи промежуточных значений.

## Тесты

Тесты store заметок (`app/stores/notes.test.ts`) покрывают следующие сценарии:

- первая инициализация с созданием двух начальных заметок и их сохранением;
- восстановление валидных заметок из `localStorage` и обработка некорректных данных;
- защита от повторной инициализации;
- создание заметки с нормализацией заголовка и пунктов чек-листа;
- сохранение существующей заметки, включая случай отсутствующей заметки;
- удаление заметки с сохранением оставшихся данных;
- работа с заметками в памяти, если `localStorage` недоступен.

Тесты модального store (`app/stores/modal.test.ts`) покрывают следующие сценарии:

- немедленное открытие модального окна с компонентом и переданными props, а также пустые props по умолчанию;
- FIFO-очередь модальных окон, переход к следующему после завершения закрытия и разрешение Promise соответствующим результатом;
- отсутствие изменений при запросе закрытия без активного окна;
- игнорирование повторного запроса закрытия и повторного завершения, пока очередь переходит к следующему окну.

Тесты редактора заметки (`app/stores/noteEditor.test.ts`) покрывают следующие сценарии:

- инициализация независимого черновика, сброс редактора и пустое состояние undo/redo;
- отмена и повтор добавления, удаления, переименования и отметки пунктов чек-листа с сохранением позиции удалённого пункта;
- debounce заголовка заметки и пункта чек-листа в 1 секунду, объединение последовательного ввода и отсутствие истории для изменения, вернувшего значение к исходному;
- немедленный flush ожидаемого ввода перед undo и атомарным изменением, ветвление истории после undo и очистка истории;
- обновление снимка черновика только при записи изменения в историю, восстановление его копии без истории undo/redo, потребление идентификатора и очистка сохранённого черновика;
- отсутствие результата восстановления, если сохранённого черновика нет.
